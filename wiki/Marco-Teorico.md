# Marco Teorico — Antecedentes

A continuacion se presentan los trabajos relacionados que sirven como fundamento para el desarrollo de la plataforma. Se analizaron investigaciones de Ecuador, Mexico y Panama en areas de SIG, recoleccion de datos movil y gestion ambiental.

---

## 1. SIG Web para Gestion de Riesgos (Ecuador)

**Referencia:** (Natalia P. Caceres & Villie Morocho, 2017)

Aborda la falta de mapas actualizados en zonas con riesgo de desastres naturales. Implementaron un SIG web que permitio a la comunidad marcar peligros en el mapa.

**Aportes clave:** Flujo captura en sitio -> almacenamiento centralizado -> validacion por experto. Recoleccion colaborativa via dispositivos moviles.

---

## 2. Visor Ambiental Universitario (Ecuador)

**Referencia:** (Sandra P. Pino C., 2018)

Desarrollo de un 'Visor Ambiental' para el campus universitario mediante ArcGIS Online.

**Aportes clave:** Transicion de archivos fisicos a sistemas digitales. Contrasta con este proyecto: Pino uso software comercial para visualizacion, SistForm se enfoca en la captura de datos en terreno.

---

## 3. Mapa Colaborativo de Seguridad (Mexico)

**Referencia:** (Abraham E. Ramirez et al., 2018)

Sistema movil para que ciudadanos reporten y georreferencien incidencias delictivas.

**Aportes clave:** GPS integrado como metodo mas rapido para captura de datos espaciales. Valida arquitectura app movil + backend. Respalda eleccion de .NET MAUI.

---

## 4. SIG para Atencion de Emergencias (Panama)

**Referencia:** (Jose O. Dutari & Pedro S. Robolt, 2019)

Implementacion de SIG en Mateo Iturralde para optimizar atencion de emergencias.

**Aportes clave:** Herramienta movil con transmision directa a panel web. Importancia del diseno de una API robusta.

---

## 5. Rastreo de Especies Amenazadas (Panama)

**Referencia:** (Marcelo M.Prado, 2021)

Rastreo de serpientes Lachesis mediante coordenadas recolectadas en zonas boscosas.

**Aportes clave:** SIG aplicado a conservacion. Identifica limitacion de herramientas comerciales (codigo cerrado, licencias). Valida necesidad de plataformas independientes.

---

## 6. Software de Geolocalizacion con React Native

**Referencia:** (Edgar E. Garcia, 2021)

App movil para capturar GPS + panel de administracion web.

**Aportes clave:** Estrategia eficiente: app movil ligera + backend robusto. Valida desarrollo multiplataforma.

---

## 7. Cambio de Cobertura de Manglares (Ecuador)

**Referencia:** (David E. Montano M., 2022)

Analisis de cambio de cobertura de manglar en Esmeraldas durante 12 anos.

**Aportes clave:** SIG como herramienta indispensable para monitoreo ambiental. Analisis espacial para evidenciar dano ecologico.

---

## 8. Gestion de Riesgos Climaticos (Ecuador)

**Referencia:** (David F. Del Salto C., 2023)

Impacto climatico en infraestructura vial y urbana en Montalvo, Ecuador.

**Aportes clave:** Uso de GeoJSON como formato estandarizado. Validacion de necesidad de captura en sitio via dispositivos moviles.

---

## 9. Visor Geografico para Gestion Municipal (Panama)

**Referencia:** (Andreina Vasquez C., 2023)

Visor geografico para optimizar tramites de visados de planos.

**Aportes clave:** Limitacion: transcripcion manual de PDFs. SistForm resuelve esto con datos digitalizados desde el origen.

---

## 10. INEGI-Movil (Mexico)

**Referencia:** (Alonso M. Meneses et al., 2020)

App "INEGI-Movil" que sustituyo formularios de papel por captura movil con soporte offline.

**Aportes clave:** Error humano como factor critico. Transcripcion manual como obstaculo. Relacion directa con arquitectura .NET MAUI.
